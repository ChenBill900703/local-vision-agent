## 最新必要範圍

1. 寵物品種分類：Oxford-IIIT Pet。
2. 紋理分類：DTD。
3. **圖片內容簡短描述：輸出圖中主要可見內容的1至2句繁體中文，必須交付。**

支援單張及資料夾批量逐張處理。使用者選任務，分類和描述可分開或依序執行。
不包含多輪聊天、OCR、框選偵測、分割或任意問答。
分類不保證辨識未知類別；描述不保證完整、精確或無幻覺。
LLM控制Agent及Qwen指定型號均非必要；描述需要另外選擇合適的小型模型，
不能只把分類標籤改成一句話冒充一般看圖描述。

完整需求、設計提案與驗收界線見 [需求規格v1.1](docs/REQUIREMENTS.md)。
本文件及該規格取代舊roadmap中的相衝突範圍與時程；不是已完成的功能清單。

## 硬體界線

- 一次只載入一個GPU模型；分類與描述依序執行並釋放。
- 禁止自動device_map與CPU／磁碟offload或共享顯存備援。
- 程序規劃上限6400MiB；預檢另要求預估模型用量後剩1536MiB。
- 顯存不足安全停止；此政策不等於已驗證的驅動硬限制。
- 描述影像token、解析度及生成token均須限制並實測，不能用參數量保證安全。

## 論文程式與圖表品質

- 程式採清楚命名、型別與單位、獨立模組、明確輸入/輸出及例外處理；註解說明研究假設
  與方法選擇，讓論文章節、演算法和實作能相互對照。
- 資料處理、模型、路由、評估與繪圖分離；參數集中且有版本，避免隱藏門檻及只靠Notebook運作。
- 正式圖表由可追溯實驗結果及繪圖程式產生，附run ID、設定版本與重建指令；保留原始數字，
  不手改測量結果或為美觀改變結論。
- 統一字型、色彩、方法名稱、小數位與排序；標示座標、單位、樣本數、切分、重複次數、
  誤差棒定義與限制；區分標準差與信賴區間，兼顧色覺差異及灰階閱讀。
- 依投稿規格輸出向量或足夠解析度影像並保留數值表；用實際論文版面大小檢查圖例、文字、
  邊界與裁切，不以3D裝飾或未說明的截斷座標軸誤導讀者。

## 實驗界線與學術倫理

1. **先訂協定。** 正式實驗前固定假設、基準、切分、seed、訓練/調參預算、checkpoint選擇、
   校準/門檻、指標、統計方式、排除條件及停止規則。探索性實驗須明示。
2. **測試集獨立。** 不用test調門檻、提示詞、前處理或模型；檢查重複及關聯樣本。
   基礎模型預訓練資料可能重疊且無法查證時，誠實列為限制。
3. **不挑結果、不漏失敗。** OOM、損壞圖片、逾時、拒答及失敗run都須記錄；說明分母、
   排除數量與原因。核對同一測試清單，報告回答比例和正確率，保留負面及無顯著差異結果。
4. **公平且可追溯。** 記錄權重來源、監督資訊、調參預算、程式版本/未提交狀態、依賴、
   資料/切分雜湊、seed、模型revision、逐圖輸出、錯誤與資源量測。
   快取重播不冒充真實端到端時間；未量測GPU用量只能標為預估。
5. **禁止造假及混用模擬資料。** 不捏造數據、引用、顯著性、核准或創新性。測試fixture、
   示意圖及模擬輸出須明示，不混入正式證據。看過結果後的改動需記錄日期、理由及探索性質，
   保留原協定與結果，不事後改寫假設為事前假設。
6. **來源與AI使用透明。** 正確引用資料、模型、論文及借用程式並保留授權；記錄AI工具用途、
   重要生成內容與人工查核。作者須理解並驗證程式及結論，依學校/投稿單位實際規範揭露AI協助。
7. **確認適用審查。** 公開資料不自動代表免審，由學校或適用審查單位確認程序。
   新增私人影像、個資、人類參與者或使用者研究前，另確認範圍、權限與同意要求。
8. **保存證據、分開公開內容。** 原始資料、權重及run保留於受控本機/備份，不放Git；
   保存来源及重現指令。可公開摘要圖表另經授權與去識別檢查，推送需使用者授權。
